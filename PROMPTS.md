# 💬 PROMPTS.md — Reusable Prompt Snippets

> Short, reusable prompts for common situations during this project, so you're not re-writing them each time. Paste directly into chat.

---

### Resume a session mid-day
> "Continuing the Solana Indexer roadmap. Check `LEARNING.md` for where I am, re-read `RULES.md`, and pick up where we left off — don't re-explain concepts already marked `[x]`."

### Ask for a hint (exercise)
> "Give me hint tier 1 (conceptual) for Exercise <day>.<n> — don't show structure or code yet."

### Request the solution
> "Here's my attempt: <paste>. I've made a real attempt — show me Solution <day>.<n> from SOLUTIONS.md now."

### Verify a decoder (Rule 16 discipline)
> "Before I trust this decoder's output, walk me through: the exact byte layout you assumed, where the discriminator/index byte came from, and how I can independently verify this against the Day 1 CLI or a block explorer."

### Request end-of-day audit
> "Audit today against ROADMAP.md's full 'You build' and 'Concepts' list before we mark it complete — list anything missing."

### Flag something as shaky
> "Mark <topic> as `[!]` in LEARNING.md — I got it working but I don't fully understand <specific part>."
